# Component 1 data

Use `python -m app.training.prepare_dataset` from `ml_component1` to inspect
`AI4A-lab/RecruitView`.

Downloaded/raw and processed data are ignored by Git. Inspect the dataset's
modalities, labels, participant identifiers and licence before extracting
features or creating a train/test split. Split by participant, not by recording,
to reduce data leakage.
